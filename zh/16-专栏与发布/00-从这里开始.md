## 在 GitHub 上怎么读更顺手

1. **用文内链接**：每篇开头有 **上篇 / 下篇 / 专栏索引**，不必退回文件夹找下一篇。  
2. **手机**：点进单篇后用浏览器阅读即可；目录大全在 [README 索引](./README.md)。  
3. **要发给同事**：复制 **单篇链接**（比只发仓库根更直达）。  
4. **收藏本篇**：浏览器收藏或 GitHub **Star** 本仓库，下次从 [仓库首页 README](../../README.md) 再进「从这里开始」。
