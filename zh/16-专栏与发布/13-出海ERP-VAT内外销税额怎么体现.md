**标题：【出海 ERP】VAT 只在本地销售列明？出口与跨境场景下，税额在系统里怎么体现**

很多出海制造主体的财务口径是：**本地内销** 在合同与发票上 **价税分离、列明 VAT**；**出口或跨境外销** 按当地规则 **不适用同一套含税展示**，或 **零税率/免税** 另轨处理。销售却习惯「一个价格报到底」；IT 若只配 **一种默认税**，月底就会出现：**收入科目对了、税额错了**，或 **发票开了、SO 上还是内销税**。

本篇衔接系列 **A4 录单五维** 与 **A5 组合码**：税务不是财务月底改凭证，而是 **订单类型 + fiscal position + 发票类型** 在创建 SO 时就分叉。

### 三个「税意图」不要混（蓝图先定义词）

| 意图 | 典型订单 | 系统展示与发票 |
|------|----------|----------------|
| **本地内销含税** | 组合 I/II 的内销 SO | 行价 **含或不含税** 按当地习惯；发票 **列明 VAT** |
| **出口/外销** | 组合 III/IV 外销 SO | 价格常为 **不含出口 VAT 或零税率**；发票类型 **出口票** |
| **进口环节 VAT** | 进口清关（非销售） | 常在 **货代服务 PO/关税**（见 A8）；**不进销售 SO 行税** |

**进口 VAT** 与 **销售 VAT** 是两条线；讨论「VAT 只在本地销售列明」时，指的是 **销售环节**，不要把进口清关 VAT 塞进外销 SO 的「税率」字段。

### SO 创建时 5 个检查点（比税率下拉更重要）

| # | 检查点 | 内销 | 外销 |
|---|--------|------|------|
| 1 | 订单类型 / 组合码 | 内销 SO | 外销 SO |
| 2 | Fiscal position | 本地含税映射 | 出口映射 |
| 3 | 价格表 | 含税价目表 | FOB/DDP 价目（税意图在附件） |
| 4 | 发票政策 | 本地增值税发票 | 出口商业发票等 |
| 5 | 分析维度 | 内销收入 | 外销收入 |

任一项仍用默认「内销」，**税额体现一定错**。

### 税额在系统里「体现」在哪（字段逻辑）

| 层级 | 内销典型 | 外销典型 |
|------|----------|----------|
| **SO 行** | 税 % 可见；含税/未税价按配置 | 税 **0 或出口税**；行备注贸易条款 |
| **发货** | 税务意图继承 SO | 同左；直发第三国仍看 **SO 税意图** |
| **发票** | 税额行、税号 | 符合出口规则；**不强行套内销税** |
| **总账** | 应交 VAT 科目 | 出口相关科目或免税科目 |
| **报表** | 内销收入+税额 | 外销收入 **单独维度** |

**票账一致**：发票税额合计应能 **追溯到 SO 列表筛选「外销」** 的子集，而不是 Excel 备注「这单算出口」。

### 与合同贸易条款（DDP/FOB）的衔接

- **DDP 外销**：合同价可能 **包干含目的国费用**；**销售 VAT 意图** 仍由 **卖方注册地规则** 决定，不等于「价格里含什么税都能塞进一个税率」。评审附件写：**本单外销、发票类型 X、是否列明 VAT**。  
- **内销 DDP 本地交付**：可能是 **含税送到客户**；与外销 **同词不同税意图**——靠 **订单类型** 区分，不靠「DDP」三个字自动判税。

### 常见反例

1. **外销 SO 套内销 15%（示例）默认税**：发票按出口开了，系统 SO 仍带内销税 — 对账永远差。  
2. **集团代购内部 SO 用终端客户税率**：内部价与税意图应 **按法人间规则**，不是终端国税率。  
3. **进口 VAT 记在销售收入贷方**：清关 VAT 应在 **进口/服务 PO 或资产** 链路（A8）。

### 一期 vs 二期

| 一期 | 二期 |
|------|------|
| 内/外销 SO **税不可默认相同**；发票类型可分 | 多法人合并报表税额抵消 |
| 出口收入报表 **按 SO 类型** | 自动转移定价税表 |

### UAT 三场景

1. **内销 SO**：开票税额与 SO 一致；报表进内销。  
2. **外销 SO**：税映射为出口；**不能**选内销默认税（或改税需财务角色）。  
3. **同物料两价格表**：内销下单不带外销税；外销下单不带内销税。
