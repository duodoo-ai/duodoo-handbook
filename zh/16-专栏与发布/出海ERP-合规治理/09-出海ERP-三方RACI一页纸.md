海外 ERP 项目里，三组人 **串行串错** 一次，就会停一个月：

- 实施商：**「财务口径没定，我们没法配凭证。」** 
- 财务：**「你们先把系统配好，我们再看账对不对。」** 
- 内部 IT：**「蓝图是乙方写的，我们只负责账号。」**

[B3「小实体治理」](./03-出海ERP-海外小实体五条最小治理.md) 里有一张 **RACI 简表**。这篇把它扩成 **可贴进 SOW 附件的一页纸**——**不写** 包干人天谈判（见 [B10](./10-出海ERP-包干人天前三锁定.md)）。

### 角色定义（海外单工厂一期 · 脱敏）

| 缩写 | 角色 | 一句话 |
|------|------|--------|
| **F** | 财务 | 定 **分录规则、报表口径**；**签字** 合规确认；**不** 配 Odoo |
| **V** | 实施商 | 在 **已签字基线** 内 **配置/开发**；交 **配置清单与交付说明** |
| **I** | 内部 IT | **环境、权限、接口、主数据** 清单；**不** 替 F 定口径 |
| **PM** | 项目负责人 | **收齐签字**、维护 [B2「双轨进度表」](./02-出海ERP-财务未签字进度作废双轨进度表.md)；**升级阻塞** |
| **S** | 数字化负责人 | **DoD 方向**、**三触发** 介入（B8）；**批** 范围基线变更 |

可选：**A** = 外审/代理（报表格式、附注）——活动行单独加，不替代 F 签字。

### 活动 RACI（R=负责 A=审批 C=咨询 I=知悉）

| 活动 | F | V | I | PM | S |
|------|---|---|---|---|---|
| **业务场景表 v1** | C | C | I | **R** | A |
| **法定报表清单** | **R/A** | I | I | C | I |
| **分录/凭证规则表** | **R/A** | C | I | C | I |
| **2.3 合规总确认** | **A** | I | I | **R** | I |
| **Odoo 单据类型/税/科目映射** | C | **R** | C | C | I |
| **接口/主数据迁移** | C | C | **R** | C | I |
| **UAT 用例（财务路径）** | **A** | **R** | C | **R** | I |
| **变更单（扩 scope）** | C | C | I | **R** | **A** |
| **Go-Live 建议** | **A** | R | R | **R** | **A** |

**硬规则**：

1. **F 列无 R 的配置活动**（如「配会计科目模板」）→ 应改 **V=R, F=C/A**。  
2. **2.3 未闭合** → V 的「可验收配置」在进度表 **可验收=否**（B2/B7）。  
3. **PM 不得** 把 F 的 **A** 写成「待定财务」——须 **具名 + 48h SLA**（链 B1 区块 D）。

### 升级路径（分歧不隔夜）

```text
项目组内对齐（PM + F + V + I）
    → 仍僵局：内部协同岗拉通（仅沟通，不决策）
    → 仍僵局：PM 书面升级数字化负责人（附行 ID + diff）
    → 范围/DoD 变更：S 批变更单 + 更新场景表版本
```

**禁止**：财务与实施商 **私下口头** 改口径不落变更单；**禁止** PM 让 F 登录 Odoo **代配** 科目。

### 项目负责人「合规工作包」（向 F 交付）

PM 主动交 **待确认清单**（不是把 F 拉进配置会）：

| 序号 | 附件 | F 输出 |
|------|------|--------|
| 1 | 场景表草案 | 签字或书面修改意见 |
| 2 | 报表清单（B1 区块 B） | 签字 |
| 3 | 分录规则样例 ≥3 条 | 规则表 v1 签字 |
| 4 | UAT 抽单计划（财务路径） | 通过标准确认 |

F **不确认** 时，PM 对 V 的谈判：**暂停** 依赖口径的条目（B10 三锁定中的场景表引用）。

### UAT 签字 RACI（可测试标准）

| 场景 | V 交付 | F 验收 | PM 动作 |
|------|--------|--------|---------|
| 本地 VAT 销售一单 | 配置 + 演示环境 | 税额/科目=规则表 # | 录 UAT 表 + 附件 |
| 进口 PO 到货一单 | 同上 | 关税/运费科目=规则表 # | 同上 |
| 期间关闭演练 | 月结 checklist | 试算平衡 + 草稿单=0 | **2.3 前置检查** |
| 法定报表样张 1 张 | 导出路径 | 与底稿差异在阈值内 | 作为 2.1 交付物 |

**签字**：F **A**；PM **R** 组织；V **R** 修缺陷；**未 A 不得 Go-Live**。

### 一期最少 3 条 + 二期 1 条（RACI 口径）

| 类型 | 内容 |
|------|------|
| 一期必做 ① | 本 RACI **贴进项目 charter/SOW 附件** 并全员过一遍 |
| 一期必做 ② | **分录规则 + 报表清单** F=R/A 闭合后再放大 V 配置 |
| 一期必做 ③ | UAT **至少 2 条财务路径** F 签字 |
| 二期延后 | 合并报表、集团口径 **新增活动行**，不塞进一期 F 的默认 R |

### ASCII：口径到配置（防串行到最后）

```text
F 定规则（签字）
    → PM 更新场景表/分录 v1 + B2 合规轨
    → V 按版本配置（变更单 #）
    → I 交接口/主数据清单
    → UAT（F 签字）
    → 2.3 总闸门（B7）
    → Go-Live
```

### 反例

1. **F 被拉进两周「凭证配置工作坊」** → RACI 崩；F 应只 **批规则表**。  
2. **V 说「标准模块不用 F 签字」** → 海外 VAT/进口费用 **必在 F 的 R 列**。
