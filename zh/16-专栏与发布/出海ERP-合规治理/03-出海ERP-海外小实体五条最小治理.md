「我们海外实体就几十号人、订单量不大，ERP 小项目嘛。」——结果 **停顿次数、范围争议、财务未签字天数**，不比国内大工厂少。小体量 **压缩的是人头，不是风险**；缺治理时，信息总监会从「放权」变成「不得不深度介入」，项目负责人会从「并行推进」变成 **两次长停**。

下面五条是 **最小治理包**（不增编制也能做），适合 **单工厂、单法人、一期进销存+财务** 类海外项目。

### ① 成功标准书面化（半页 charter）

| 必写 | 示例句 |
|------|--------|
| DoD | 见 B1：**合规账务 + 法定报表** 签字，不是 Go-Live |
| 非目标 | 制造 APS、合并报表 **本期不做** |
| 上线日 | 日期 + **依赖合规总确认** 的条件 |

口头「先把系统搭起来」= 成功标准未共识。

### ② 合规门禁前置（WBS 最前段）

```text
场景表 → 法定报表清单 → 分录规则 → 【财务实际确认日】→ 再放大开发
```

未过门禁的开发工时 **记入乙方消耗，不计入可验收进度**（B2 双轨表）。

### ③ 授权边界（数字化负责人 / 项目负责人）

| 平时 | 升级触发（满足任一即介入） |
|------|----------------------------|
| 看 **可验收进度** + 风险表 | 范围漂移无变更单 |
| 不逐条审配置 | **合规未确认仍批大开发** |
| | 里程碑 **连续两次** 未达成 |

写进 charter，避免「全程细管」和「完全放羊」两极。

### ④ 周度可验收产物（artifact，不是口号）

| 每周至少 1 个 | 不合格示例 |
|---------------|------------|
| 场景表 diff / 分录样张 / UAT 抽单结果 | 「本周配了很多字段」 |
| 进度表行 ID + 实际完成日 | 只发菜单截图 |

「卡时间、卡结果」= **能 diff 的文件或签字页**。

### ⑤ 触发式管理层介入 + 三方 RACI 简表

| 角色 | 定什么 | 配什么 | 签什么 |
|------|--------|--------|--------|
| 财务 | 规则、报表口径 | 不替乙方配 Odoo | 合规确认 |
| 乙方 | 按签字基线配置 | 不擅自扩范围 | 交付清单 |
| 项目负责人 | 收齐签字、进度表 | 协调实施商/财务/IT | 升级阻塞 |
| 数字化负责人 | DoD 方向 | 触发介入 | 批范围基线变更 |

分歧升级：**内部协同 → 项目负责人 → 数字化负责人**；财务不确认 **不得** 用「国外项目难」跳过。

### 一期边界提醒（与 A 组互链）

小实体仍可能有 **外销+进口+自产** 组合；治理五条 **不替代** 场景表（A1/A5），但保证 **场景未定稿时不堆功能**。
