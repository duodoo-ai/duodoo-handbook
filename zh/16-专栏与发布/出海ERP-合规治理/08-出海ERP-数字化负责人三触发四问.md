海外 ERP 一拖延，会议室里常见两种极端：

- **数字化负责人**：「我天天盯你们周会。」→ 项目组只会 **报现象**，不会 **交 artifact**。  
- **数字化负责人**：「小项目你们自己跑。」→ **成功标准没写死**，财务没签字，开发却跑到 80%——最后只能 **深度介入救火**。

[B3「小实体治理」](./03-出海ERP-海外小实体五条最小治理.md) 里 **③ 授权边界** 只有半张表。这篇把 **「什么时候必须下场」** 和 **「平时怎么问才不拖成理念辩论」** 写满——**不写** charter 五条全文，**不写** 协同岗边界（另篇）。

### 平时：数字化负责人只看什么（不进场）

| 输入 | 频率 | 不问什么 |
|------|------|----------|
| [B2「双轨进度表」](./02-出海ERP-财务未签字进度作废双轨进度表.md) **合规闭合率 + 可验收进度** | 每周或双周 | 某个 Odoo 菜单怎么配 |
| 风险表（已变任务？） | 同上 | 乙方和财务谁对谁错 |
| 下一里程碑 **日期 + 交付物名称** | 同上 | 「国外项目难不难」 |

**原则**：过程风险在项目组内消化；**未触发** 下节三条件时，**不参加** 周例会即兴改 scope。

### 深度介入：三触发（满足任一即升级）

| # | 触发条件 | 可观测信号 | 介入动作（48h 内） |
|---|----------|------------|-------------------|
| **T1** | **范围漂移** | 无变更单的新模块/新法人/新贸易路径进入开发 | 冻结 3.x 配置；开 **范围 diff 会** 或排 [B5「对齐会三件套」](./05-出海ERP-先总后分90分钟专项对齐会.md) 只审变更 |
| **T2** | **合规未确认仍扩开发** | [B7「2.3 总闸门」](./07-出海ERP-23总闸门四字段.md) **2.3 实际确认日** 为空，但乙方人天/开发轨仍在涨 | 宣布 **实施进度未生效**；只允许不依赖口径的通用项 |
| **T3** | **里程碑连续两次未达成** | 同一里程碑（如场景表 v1、2.3 总闸门）**两个汇报周期** 仍无实际完成日 | 数字化负责人 + 项目负责人 **书面** 下一里程碑；必要时调整资源或升级财务 SLA |

**未触发时**：数字化负责人 **不** 用个人经验 **口头校正** 锚点代替 **财务签字件**——方向可以讲，但 **书面 DoD** 仍归 [B1「合规 DoD」](./01-出海ERP-上线成功不是GoLive是合规账务与法定报表.md) + 项目负责人推动。

### 平时四问（冲刺末 / 月度 · 可打印）

不把复盘开成「先总后分 vs 先流程」辩论；**只问四件事**：

| 问 | 合格回答 | 不合格回答 |
|----|----------|------------|
| **1. 范围变没变？** | 「无变更 / 变更单 # + diff 附件」 | 「差不多吧」 |
| **2. 下月交付物是什么？** | 「行 ID + 文件名 + 谁签字」 | 「继续开发」 |
| **3. 谁负责？** | 每个交付物 **唯一 R**（见 B9 RACI） | 「大家一起」 |
| **4. 风险是否已变成任务？** | 风险表有 **负责人 + 截止日** | 「财务还没回」无任务 |

**四问耗时**：30 分钟以内；答不齐 → **不批准** 扩大乙方范围。

### 介入后：数字化负责人 **不做** 什么

| 不做 | 谁做 |
|------|------|
| 替财务定分录/报表口径 | 财务 + 项目负责人收签字 |
| 替实施商做 Odoo 配置 | 乙方 + 内部 IT |
| 替项目负责人写进度表每一行 | 项目负责人维护 B2 |
| 通过协同岗间接决策 | 决策仍归项目负责人（协同边界见 B15 选题） |

### 10 条清单

1. charter 是否 **书面** 写了「三触发」（可引用 B3 ③，详表本篇）？  
2. 周报是否 **只报** 合规闭合率 + 可验收进度？  
3. **T2** 是否与 **2.3 总闸门** 绑定？  
4. 里程碑是否 **有行 ID** 可判「连续两次未达成」？  
5. 四问是否 **每月至少一次** 有纪要？  
6. 未触发时数字化负责人是否 **缺席** 配置细节会？  
7. 触发 **T1** 是否 **先冻结** 再谈？  
8. 是否 **禁止** 用开发人天替代合规进度？  
9. 财务未确认前是否 **不批** 大范围乙方加班？  
10. 介入后是否 **输出书面** 下一里程碑（不是口头「抓紧」）？

### 反例

- **每周旁听周会** 但三触发从未启用 → 团队学会 **表演进度**，不会 **交签字页**。  
- **2.3 空着仍庆功 Go-Live 计划** → 数字化负责人只批评财务，**不触发 T2** = 治理失效。
