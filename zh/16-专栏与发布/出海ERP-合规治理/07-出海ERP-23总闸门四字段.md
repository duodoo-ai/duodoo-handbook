[B2「双轨进度表」](./02-出海ERP-财务未签字进度作废双轨进度表.md) 讲的是：**怎么建 Sheet、怎么算可验收进度**。这篇更窄——只讲一行。

海外项目里，进度表常常 **几十行销售/库存/接口**，但 **没有一行能回答 CFO**：「合规账务与法定报表，财务到底签没签？」  
这一行在 WBS 里应落在 **2.3 合规总确认**（与 [B6「WBS 五层」](./06-出海ERP-WBS第一层只留五顶.md) 的 **2 合规确认** 对应）。我把它叫 **总闸门行**：**四字段填齐之前，5 上线 在语义上不能绿。**

### 合规轨 2.1～2.3：三行分工（别混成一行口号）

| WBS | 行名（进度表） | 交付物（可引用 B1 附件） | 四字段谁主填 |
|:---:|----------------|--------------------------|--------------|
| **2.1** | 法定报表清单确认 | 报表清单 + 口径说明 | 财务对接人填 **实际确认日** |
| **2.2** | 分录/凭证规则确认 | 分录规则表 v1 | 同上 |
| **2.3** | **合规账务与法定报表总确认** | 总确认纪要或签字 PDF | **必须**有 **实际确认日** |

**2.1、2.2** 可以分步签字；**2.3** 是 **总闸门**——表示财务（或授权外审）认：**在已锁场景下，账能出、表能交**。  
可以前三项合并一次签字，但进度表里 **2.3 的「实际确认日」仍不能为空**；否则周报里的「合规闭合率」会 **虚高**（B2 算法：按行数计，缺 2.3 仍缺总闸门）。

### 四字段定义（复制进 Excel 表头备注）

| 字段 | 含义 | 填错后果 |
|------|------|----------|
| **项目负责人** | 推动确认、催交材料、升级阻塞的人 | 财务不知道找谁 → 确认拖延算 PM 职责内 |
| **财务对接人** | 能代表财务口径或 48h 内书面回复的人 | 填成 IT → 签字无效 |
| **计划确认日** | 场景/规则齐备后 **承诺** 财务反馈的日期 | 只填上线日不填此项 → 无法看漂移 |
| **实际确认日** | 财务 **书面** 结论落地的日期 | **空 = 总闸门未开** |

**硬规则（与 B2 一致，本篇强调 2.3）**：

- **2.3 实际确认日为空** → 项目 **整体上线计划标「高风险」**；对管理层 **不得** 用开发配置率代替可验收进度。  
- **2.3 未开** → WBS **3.x 实施商交付** 在进度表里 **可验收=否**（即使菜单已配好）。  
- **5 Go-Live** 行 **依赖** 2.3 实际确认日（可设公式或人工门禁）。

### 2.3 一行示例（脱敏 · 贴进 Sheet2）

| 行 ID | WBS | 轨 | 项目负责人 | 财务对接人 | 计划确认日 | 实际确认日 | 交付物 | 可验收？ |
|-------|-----|----|------------|------------|------------|------------|--------|----------|
| G1 | 2.3 合规总确认 | 合规 | 海外 ERP PM | 工厂财务经理 | *(计划日示例)* | *(空)* | 总确认 PDF | **否** |

> **表示例**：计划确认日填 **相对项目基线的日期**（Excel 单元格），勿绑定发稿月份；实际确认日仍须财务书面填写。

周报话术固定：**「2.3 总闸门：未闭合；合规闭合率含 2.3 为 0/N；可验收进度不随开发行上升。」**

### 与 B1 DoD 的对应（不写第二遍模板）

[B1「合规 DoD」](./01-出海ERP-上线成功不是GoLive是合规账务与法定报表.md) 里的 **签字方、截止日期** → 填进 **计划确认日**；  
DoD 附件 **场景表 + 报表清单 + 分录规则** → 2.1/2.2 交付物列；  
**2.3** = DoD 在进度表上的 **「财务已认账」开关**。

### 8 条清单（本篇独占 · 建表见 B2）

1. 进度表是否有 **独立 2.3 行**（不是写在备注里）？  
2. 四字段是否 **列名一致**（便于乙方/IT 协作）？  
3. **实际确认日** 是否 **仅财务/授权人** 可改？  
4. 2.1/2.2 未闭合时，是否 **仍禁止** 报整体上线 %？  
5. Go-Live 行是否 **公式依赖** G1 实际确认日？  
6. 包干 SOW 上线日是否 **写「依赖 2.3」**（链 B10）？  
7. 复工 SOP 是否 **先更 2.3 计划日** 再扩 3.x（链 B12）？  
8. 对齐会三件套版本号是否 **写在 2.3 交付物备注**（链 B5）？

### 反例

- **M2/M3 有签字、2.3 空着** → CFO 仍可以说「总确认没有，不算验收进度」。  
- **把 2.3 实际确认日填成 Go-Live 当天** → 假闸门；应是 **财务认账早于或等于** 上线决策点。

### 一期 3 条 + 二期 1 条（闸门口径）

| 类型 | 内容 |
|------|------|
| 一期必做 ① | 2.1+2.2+2.3 **行存在** 且 2.3 有 **计划确认日** |
| 一期必做 ② | 2.3 **实际确认日** 闭合后才开 **5 Go-Live** |
| 一期必做 ③ | 周报 **只报** B2 的合规闭合率 + 可验收进度 |
| 二期延后 | 合并报表、集团口径 **不进 2.3**，写 1.2 非目标 |
