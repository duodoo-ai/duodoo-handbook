海外 ERP 周报里最气人的一行：**开发完成 85%**。CFO 问：**财务确认合规账务了吗？** 答：**还在对齐。**——那 85% 在验收语义下 **等于 0%**。

双轨进度表：**左轨** 实施/配置（乙方+IT）；**右轨** 合规确认（财务/外审）。**右轨没有「实际确认日」的行，左轨完成率不得计入项目可验收进度。**

### 表头怎么设（直接建 Sheet）

**Sheet1 · 里程碑双轨**

| 行 ID | WBS 项 | 轨 | 负责人 | 计划完成 | 实际完成 | 交付物 | 可验收？ |
|-------|--------|----|--------|----------|----------|--------|----------|
| M1 | 业务场景表定稿 | **合规** | 项目负责人 | | | 签字 PDF | 否，直到实际完成 |
| M2 | 法定报表清单确认 | **合规** | 财务 | | | 清单+签字 | 否 |
| M3 | 分录规则表确认 | **合规** | 财务 | | | 规则表 v1 | 否 |
| D1 | 销售模块配置 | 开发 | 乙方 | | | 配置清单 | **仅当 M1–M3 均有实际完成日** |
| D2 | 库存/采购配置 | 开发 | 乙方 | | | 同上 | 同上 |
| … | … | … | … | … | … | … | … |

**轨** 列只允许两值：`合规` | `开发`。**可验收？** 用公式或人工规则：**任一前置合规行缺实际完成日 → 本开发行可验收=否**。

### 「合规确认行」最低 4 行（与 B7 一致）

| 合规行 | 4 字段（必填才开开发轨） |
|--------|--------------------------|
| 场景定稿 | 负责人、财务对接人、计划确认日、**实际确认日** |
| 法定报表清单 | 同上 |
| 分录/凭证规则 | 同上 |
| **合规账务与法定报表总确认** | 同上（可与前三合并签字，但 **实际确认日** 不能为空） |

### 完成率怎么报（给管理层）

| 指标 | 算法 | 用途 |
|------|------|------|
| **开发配置率** | 开发轨「实际完成」行数 / 开发轨总行数 | 乙方人天、IT 排期 |
| **合规闭合率** | 合规轨已填 **实际确认日** 行数 / 合规轨总行数 | **项目真实健康度** |
| **可验收进度** | 仅统计「可验收？=是」的开发行 | **对 CFO 的唯一进度** |

**周报固定一句**：「合规闭合率 X%；可验收进度 Y%。未闭合项：{列出合规行 ID}。」

### 10 条清单

1. 进度表是否有 **「轨」** 列？没有则加。  
2. 合规行是否 **不少于 4 行**（场景、报表清单、分录、总确认）？  
3. 开发行是否 **挂 WBS 父项**（场景定稿→合规→实施→UAT→上线）？  
4. **实际确认日** 是否只允许 **财务/授权人** 填写？  
5. 未闭合合规时，是否 **禁止** 报「整体上线 %」？  
6. 乙方 KPI 是否绑定 **可验收进度** 而非人天消耗？  
7. 每次「推一下停一下」复工前是否 **先更双轨表**？  
8. 会议纪要是否 **引用行 ID**（如 M2 延期）？  
9. 外审/代理节点是否在合规轨 **单独一行**？  
10. 上线 Go-Live 行是否 **依赖** 合规总确认行的实际完成日？

### 反例

- **只截 Odoo 菜单图** 当进度 → 合规轨全空。  
- **UAT 条数 300** 但 M2/M3 无签字 → 可验收进度仍为 0。
