**标题：【出海 ERP】齐套不够怎么办？原材料、包材、辅料采购到底谁触发**

> 专题「工贸 ERP · 分期与验收」见 [专栏索引](./README.md)  
> 上篇：[续读](./09-出海ERP-四种经营组合主数据怎么建.md)  
> 下篇：[续读](./11-出海ERP-进口直采还是集团代购.md)

[合同评审](./07-出海ERP-合同评审单从接单到排产.md) 通过后，计划最常问的一句是：**「料够不够排产？」** 采购的回击是：**「谁下的单、什么料、走本地还是进口？」** 若系统里没有 **触发规则**，就会变成：计划微信群 @ 采购、采购 Excel 算缺口、财务月底才看见 **进口货代费** 挂在错误科目上。

这篇专讲 **自产路径**（有 MO）在齐套不足时，**原材料、辅助材料、包装材料** 分别 **谁触发、触发什么单据**；并与 [经营组合主数据](./09-出海ERP-四种经营组合主数据怎么建.md) 里的 **内采/外采** 对齐。转口贸易无 MO 的采购触发，走贸易 PO 分支（见 [决策树](./05-出海ERP-没库存时自产自销还是转口贸易.md)），不在本篇展开生产领料。

### 三类物料，三种节奏（主数据先标清）

| 类别 | 典型例子（脱敏） | 提前期 | 触发敏感度 |
|------|------------------|--------|------------|
| **原材料** | 进口主料、本地大宗料 | 长（海运+清关） | 最高；评审必写齐套假设 |
| **辅助材料** | 添加剂、耗材 | 中 | MO 确认后常才暴露缺口 |
| **包装材料** | 托盘、纸箱、标签 | 短但易断 | 常被遗忘，导致成品无法入库发运 |

**一期必做**：物料主数据 **采购类别** 字段（原料/辅料/包材），BOM 展开时按类别 **分报表**；评审附件 **缺料清单** 按三类分列，不要一个「缺料」合并项糊弄老板签字。

### 齐套检查发生在哪几个闸门

```text
评审通过（书面齐套假设、在途是否计入承诺）
    → 计划齐套运算（库存 + 在途 PO + 可选在产）
    → 缺口清单
    → 采购申请 / PO（分轨）
    → MO 下达（建议：关键料齐套或「允许欠料开工」书面批）
    → 领料 → 完工入库 → 发货（A2 三问）
```

**两个「谁触发」不要混为一谈**：

1. **触发采购**：缺口清单 → **采购员或 MRP** 生成 PR/PO（本地/进口/服务）。  
2. **触发生产**：**计划员** 下达 MO；系统应可配置 **未齐套禁止确认 MO** 或 **允许欠料开工需审批**（二选一写进 SOW）。

### 触发矩阵（蓝图附件可直接贴）

| 缺口类型 | 谁发起 | 系统动作 | 单据 | 批准 |
|----------|--------|----------|------|------|
| 原料、本地可买 | 计划/MRP | 自动或半自动 PR | **本地采购 PO** | 采购经理；超金额财务 |
| 原料、仅进口 | 计划/MRP | PR 带 **进口类型** | **进口 PO** + 可选 **货代服务 PO** | 采购+财务（关税/运费） |
| 集团代购通道 | 计划 | PR 指定 **代购供应商** | 进口 PO（结算路径见 A5） | 同进口 |
| 辅料缺口 | MO 确认后 MRP | PR | 本地 PO 为主 | 采购 |
| 包材缺口 | MO 确认或首道工序前 | PR **加急标记** | 本地 PO | 计划+采购 |
| 进口段费用 | 采购/货代对账 | 服务收货 | **货代服务 PO**（关税/运费/报关/VAT 分项） | 财务按附件科目 |

**货代服务 PO** 与 **物料 PO** 分开，是出海工厂财务不炸的关键——进口段费用不要打成「物料单价」一行糊掉。

### MRP 自动 vs 手工 PR：一期怎么选

| 模式 | 适用 | 风险 |
|------|------|------|
| **MRP 自动补货** | 本地辅料、包材；提前期稳定 | 进口主料若自动下单，可能 **错币种/错供应商** |
| **缺口报表 + 人工 PR** | 进口原料、新 BOM、试制 | 人力高，但 **可控** |
| **评审后一次性锁定需求** | 项目型订单 | SO 行数量变更 → **变更重评**（A3） |

**专家建议（一期）**：进口主料 **默认人工 PR**（系统只出缺口，不自动 PO）；本地包材可 MRP。**评审附件** 勾选「本单是否允许 MRP 自动下进口 PO」——默认 **否**。

### 齐套公式与采购触发的衔接（与 A3 一致）

计划可用量公式见 [评审篇](./07-出海ERP-合同评审单从接单到排产.md)；采购触发前应输出 **结构化缺料表**：

```text
缺料量（组件行）= BOM 需求（含损耗）
                − 仓库可用（已质检）
                − 已分配给其他 MO/SO 的预留
                + 是否计入在途 PO（按评审勾选）
```

**在途进口不计入** 时，采购触发仍应发生，但 **MO 下达闸门** 应更严——避免「海上已有货」却 **开工占料** 其他订单。

### 本地采购合同 vs 进口合同（系统必须分轨）

| 维度 | 本地 PO | 进口 PO |
|------|---------|---------|
| 供应商 | 本地合格供应商 | 进口合格 + 有时集团代购 |
| 币种/付款 | 本币为主 | 外币、信用证等 |
| 伴随单据 | 送货单 | 提单、报关单、清关 |
| 费用 | 本地运费 | 常另挂 **货代服务 PO** |
| 报表 | 本地采购分析 | 进口采购分析、关税汇总 |

同一缺口 **禁止** 用本地 PO 类型走进口清关——类型错了，后面 **成本与 VAT** 全错，不是仓库能改的。

### MO 下达与采购的先后顺序（写进 SOP）

| 策略 | 规则 | 适用 |
|------|------|------|
| **严齐套** | 关键原料（BOM 上标记）到货或 **在途已预留** 才允许 MO 确认 | 进口主料长提前期、少插单 |
| **欠料开工** | 书面批 + 系统审批；仅非关键辅料可欠 | 产能紧、包材后到 |
| **拆 MO** | 先产有料部分 | 评审允许拆单（A3） |

**关键原料清单** 由质量/工艺在 BOM 发布时标记；IT 只负责 **把标记做成 MO 确认校验**。

### 常见反例

1. **包材未进 BOM**：成品入库了，没有托盘无法装柜——包材应 **BOM 或包装工序** 强制展开，缺则 PR。  
2. **进口料一条 PO 含运费关税**：财务无法分拆 **到岸成本**——物料 PO 与服务 PO 分离。  
3. **计划绕过评审直接下 MO**：采购触发全乱——未 **评审通过** 的 SO **禁止** MO（A3 UAT）。  
4. **贸易品走 MO 领料**：仅采购品不应 MO——物料 **Buy only**（A5）。

### 与出库、组合的衔接

- 组合 **II/IV**（含进口采）最易触发 **进口 PO + 服务 PO**（A5）。  
- 发货前仍走 [出库三问](./06-出海ERP-销售出库前系统必须回答的三个问题.md)；齐套解决 **能不能产**，三问解决 **能不能发**。  
- 直发第三国：进口 PO 收货方、MO 完工入库仓、销售发货 **收货地址** 三者可能不同，缺料触发时 PR 上 **收货仓库** 必须对。

### 方案级映射（不限定品牌）

| 业务步骤 | 典型对象/配置 |
|----------|----------------|
| 缺口运算 | MRP、补货规则、或自定义报表 |
| PR → PO | 采购类型路由到本地/进口序列 |
| 服务费用 | 服务类产品 + 货代供应商 |
| MO 闸门 | 制造单确认前校验：评审状态 + 可选齐套 % |

### 一期 UAT（三单）

1. **本地原料+包材**：MO 确认 → 自动生成/手工 PR → 本地 PO 到货 → 领料完工。  
2. **进口主料缺口**：评审勾选在途不计入 → 缺口表有量 → **进口 PO + 服务 PO** 分两张；MO 闸门符合 SOW。  
3. **欠料开工（若启用）**：无审批 **禁止** 确认 MO；批后允许，缺料行可追踪。

三条在测试库跑不通，验收报告勿写「采购与生产已集成」。
