**标题：【出海 ERP】内销外销 × 内采外采：四种经营组合，主数据怎么建才不糊账？**

> 延伸阅读「出海 ERP」第 5 篇 · 2026-10-27 发布  
> 专题「工贸 ERP · 分期与验收」见 [专栏索引](./README.md)  
> 上篇：[续读](./08-出海ERP-国内国外客户两套销售口径怎么录单.md)  
> 下篇：[续读](./10-出海ERP-齐套不够采购谁触发.md)

出海制造主体最常见的业务骨架，可以压成一句话：**销售分内/外，采购分内/外，履约分自产/贸易**（见本专栏 [决策树篇](./05-出海ERP-没库存时自产自销还是转口贸易.md)）。很多 ERP 烂尾，不是模块没买齐，而是 **主数据按「一个客户、一个供应商、一种订单」建到底**——月底内销 VAT、出口免税、进口 PO、贸易 PO 全挤在一张 Partner 和几个默认项里。

这篇把 **四种经营组合（销售×采购）** 和 **第三条轴（自产/贸易）** 写成 **主数据蓝图**：上线前工作坊能勾表，一期验收能抽四格 UAT，合并报表二期再谈也不耽误法人内关账。

### 先分清三个维度（别混成「四种产品」）

| 维度 | 业务问法 | 系统里建议落点 |
|------|----------|----------------|
| **销售口径** | 本单算内销还是外销/跨境？ | 销售订单类型、税/fiscal、价格表、分析维度 |
| **采购口径** | 本单料从本地买还是进口买？ | 采购订单类型、供应商资质、币种/付款、货代服务 PO |
| **履约路径** | 有库存发、自产、还是贸易直采？ | 与 [评审](./07-出海ERP-合同评审单从接单到排产.md)/MO/贸易 PO 分支一致 |

**四种组合** 指的是 **销售×采购** 的 2×2；**自产/贸易** 是 SO 确认后的 **履约分支**，与组合码 **正交**。同一「外销 + 进口采」订单，可以走自产（MO+进口 PO）或走贸易（贸易 PO+直发），不能靠改客户名切换。

### 2×2 经营组合表（蓝图工作坊必画）

|  | **内采**（本地/本国供应商） | **外采**（进口/跨境供应商） |
|--|---------------------------|-----------------------------|
| **内销** | **组合 I**：本地卖、本地买；VAT/本地发票；常见本地仓 | **组合 II**：本地卖、进口料；进口 PO + 清关；内销价含/不含税要写清 |
| **外销** | **组合 III**：出口卖、本地买；出口 fiscal；本地采购喂出口 MO | **组合 IV**：出口卖、进口买；进口+生产+出口发运；费用链最长 |

每一格要书面回答：**默认 SO 类型、默认 PO 类型、默认仓库、默认税、默认分析账户**——不是让销售每次手选八个字段。

### 组合码 + 默认带出（一期最小可行）

建议在 **销售订单类型**（或等价的「经营组合」枚举）上挂 **组合码 I～IV**，确认 SO 时 **只读展示**，由类型带出：

| 组合码 | 典型场景（脱敏） | SO 默认 | PO 默认（缺料时） | 财务备注 |
|--------|------------------|---------|-------------------|----------|
| **I** | 本国终端、本地原材料 | 内销 SO | 本地采购 PO | 本地 VAT 规则 |
| **II** | 本国终端、进口主料 | 内销 SO | 进口 PO + 可选货代服务 PO | 进口关税/运费进成本规则写附件 |
| **III** | 境外关联/出口、本地包材辅料 | 外销 SO | 本地采购 PO | 出口映射；与 [录单五维](./08-出海ERP-国内国外客户两套销售口径怎么录单.md) 一致 |
| **IV** | 境外订单、进口丝材/主料 | 外销 SO | 进口 PO；集团代购走 **指定供应商+合同类型** | 进口段与出口段费用分轨 |

**集团代购**（兄弟公司代采进口料）在组合 IV 里最常见：供应商主数据可能是 **集团内贸易公司**，但 **收货仓库、清关主体、付款方** 仍是本工厂法人——主数据上要 **供应商角色** 与 **结算路径** 分开字段，不要一个 Partner 包到底。

### 主数据对象清单（按对象建，不按「部门习惯」建）

| 对象 | 必须区分的属性 | 与组合的关系 |
|------|----------------|--------------|
| **客户（Partner）** | 内销/外销客户分类；集团关联标记；开票/收货联系人 | 不代替组合码；同一客户不同项目可不同组合 |
| **供应商** | 本地/进口；是否货代；是否集团代购通道 | 进口 PO 只能选「进口合格」供应商 |
| **物料** | 采购类型（买/造）；进口监管/认证；默认供应商（分本地/进口） | BOM 行可覆盖默认 |
| **BOM/工艺** | 版本号；临时料标记 | 评审锁定版本（见 A3） |
| **仓库** | 本法人仓；在检仓；贸易库存仓（若有） | 组合 I/III 常同一成品仓；贸易库存 **独立仓** 可避免假生产 |
| **公司/分支** | 法人账套 | 一期 **一法人一账** 优先 |
| **分析维度** | 内/外销、区域、产品线 | 从 SO 类型带出，禁止月底 Excel 补标 |

### 第三条轴：自产 / 贸易 如何挂在组合上

```text
SO 已确认（组合码 I～IV 已带出税、价、分析维度）
    → 库存决策（A1 决策树）
    → 有库存：发货（组合只影响税与价格，不新建 MO）
    → 无库存：
          ├─ 自产：评审 → 齐套 → 本地/进口 PO → MO
          └─ 贸易：评审 → 贸易 PO（+直发）→ 禁止假 MO
```

**主数据错误的高频点**：组合 IV 外销+进口采的 **贸易单** 被建成 **MO**——BOM 里没有、成本却走生产。应在 **产品主数据** 上标 **「可制造 / 仅采购」**；仅采购品 **禁止** 生成 MO。

### 合并报表：一期做还是二期做？

| 策略 | 一期主数据 | 二期 |
|------|------------|------|
| **只上工厂法人** | 组合码、内/外销、进口/本地 PO 分轨；集团客户标关联 | 集团 intercompany 价目表、自动镜像 PO/SO |
| **集团+工厂同期** | 各法人独立组合码； **内部客户/内部供应商** 清单 | 抵消分录、转移定价 trail |

SOW 写死：**一期以工厂法人关账为准**；组合表四格在 **测试库各跑通一单**，比 PPT 写「支持多组织」更有用。

### 主数据治理（RACI 简表）

| 事项 | 销售 | 采购 | 计划 | 财务 | 质量 | IT |
|------|:----:|:----:|:----:|:----:|:----:|:--:|
| 客户分类/集团标记 | R | I | I | C | I | A 配置 |
| 供应商本地/进口资质 | I | R | I | C | C | A |
| 物料可制造/仅采购 | C | C | R | I | R | A |
| BOM 版本发布 | I | I | R | I | A | 发布权限 |
| 组合码与订单类型映射 | C | C | C | A | I | R 实现 |

**A=审批发布**（财务或数据治理负责人）；业务 **不能** 在 live 库随意改组合默认值而不走变更。

### 常见反例（专家现场）

1. **一个供应商兼本地与进口**：进口合同走了本地 PO 类型，关税进费用科目混乱——应 **同一法人下两个供应商记录** 或 **供应商上「默认 PO 类型」不可覆盖**（除采购经理角色）。  
2. **外销 SO 用内销组合码**：税对了、分析维度错，老板看「出口收入」为 0——组合码应在 **订单类型** 层锁死。  
3. **集团代购未标「结算路径」**：PO 付给集团、货进本厂，对账靠微信——应在 PO 上 **合同号、代购协议号、最终供应商** 三字段留痕。

### 与录单、评审的衔接

- [A4](./08-出海ERP-国内国外客户两套销售口径怎么录单.md) 解决 **客户与税**；本篇解决 **组合码与 PO/SO 默认**。  
- [A3](./07-出海ERP-合同评审单从接单到排产.md) 评审单应 **只读显示组合码 + 履约路径**；变更组合或路径 → **变更重评**。  
- [A6 齐套采购触发](./10-出海ERP-齐套不够采购谁触发.md)（续篇）在组合 IV 下展开 **谁下进口 PO**。

### 方案级映射（Odoo / 年费套件通用逻辑）

| 概念 | 典型实现 | 验收点 |
|------|----------|--------|
| 组合码 | SO 类型 / 团队 / 自定义 selection | 新建 SO 选类型后税与仓库不可误改 |
| 内/外采 | PO 类型 / 操作类型 / 序列 | 进口 PO 报表可筛选 |
| 仅采购品 | 物料 route：Buy only | 该料 **无法** 出现在 MO 组件需求之外的「生产」 |
| 贸易库存 | 独立库位 + 路线 | 贸易单 **无 MO** 可出库 |

### 一期 UAT：四格各一单（最小集）

| 用例 | 组合 | 通过标准 |
|------|------|----------|
| U1 | I 内销+内采 | SO 含税正确；本地 PO 入库；可发货 |
| U2 | II 内销+外采 | 进口 PO 与货代 PO 可区分；成本进库存规则符合附件 |
| U3 | III 外销+内采 | 外销 fiscal；MO 领本地包材；出口发运单类型正确 |
| U4 | IV 外销+外采 | 进口 PO 齐套后 MO；或明确走贸易无 MO |

任一格只能在 Excel 模拟、系统里选不对类型，**主数据阶段即失败**，不要进入「上线后培训销售记得选」。
