**标题：【出海 ERP】合同评审单：从接单到排产，中间别缺这一张**

> 延伸阅读「出海 ERP」第 3 篇 · 2026-10-21 发布  
> 上篇：[销售出库前三问](./06-出海ERP-销售出库前系统必须回答的三个问题.md) · 下篇：[内外客户录单](./08-出海ERP-国内国外客户两套销售口径怎么录单.md) · [专栏索引](./README.md)

很多海外制造项目的系统蓝图里，**销售订单（SO）** 画得很满，**合同评审 / 订单评审** 却只有口头一句「计划部看一下」。结果是：SO 已确认、MRP 已跑、采购已在催进口料，评审会上才发现 **工艺未批、认证不齐、贸易条款与 BOM 不一致**——这不是计划部慢，是 **流程上少了一张「允许排产」的闸门**。

我在 **海外制造基地**（内销+外销、本地采+进口采、自产+贸易）类场景里，业务骨架往往是：**销售两种、采购两种**；无本地库存且走自产时，输入不应只有 SO，而应经过 **合同评审单（或等价的订单评审）** 再进入排产。这篇把 **评审→齐套→采购→生产→入库** 说清楚，并对齐 [自产/贸易决策树](./05-出海ERP-没库存时自产自销还是转口贸易.md)：走「自产自销」分支的订单，**默认不许跳过评审**。

### 评审单到底审什么（给老板一张签字表）

建议评审结论里 **书面回答** 下面几类问题，而不是只写「同意生产」：

| 维度 | 评审要问的 | 一期系统建议留痕 |
|------|------------|------------------|
| **范围** | 本单产品与数量是否在已批工艺/BOM 内？是否含临时物料？ | 评审状态、关联 SO 行、BOM 版本号 |
| **齐套** | 关键料本地/进口何时到？是否允许拆单交付？ | 齐套日期、缺料清单、假设说明 |
| **贸易** | 内销还是外销？VAT/出口意图？DDP/FOB 谁承担哪段费用？ | 订单类型、贸易条款模板（见 [决策树](./05-出海ERP-没库存时自产自销还是转口贸易.md) 价外费用） |
| **产能** | 当前产线是否排满？是否挤占其他已承诺订单？ | 计划优先级或排程备注 |
| **法人** | 本单在哪个法人主体下生产、开票、出库？ | 公司/仓库/日记账维度 |

**老板签字** 可以是「评审通过，允许下达生产」；**IT 签字** 是「系统里未评审的 SO 不能生成 MO / 不能锁料」。两条线缺一，上线后还是会回到微信群判案。

### 评审状态机（蓝图里必须画出来）

| 状态 | 含义 | 允许的操作 | 禁止的操作 |
|------|------|------------|------------|
| **草稿** | SO 已录入，未提交评审 | 改数量、交期、价格 | 下 MO、锁料、采购申请 |
| **待评审** | 已提交，计划/采购/财务会签中 | 补充附件、评论 | 下 MO、对外确认交期（书面） |
| **通过** | 书面结论：路径+齐套假设已锁定 | 齐套运算、下 MO、开 PO | 擅自改 SO 数量/BOM 不触发重评（应走变更） |
| **驳回** | 不具备排产条件 | 改 SO 或关单 | 任何生产与定向采购 |
| **变更重评** | SO 关键字段变更后 | 仅评审岗重开 | 沿用旧「通过」状态直接生产 |

**关键字段**（建议写进 SOW）：产品/数量、BOM 版本、贸易条款、收货国、履约路径（产/贸/现货）、法人主体。**改了就应回到「待评审」或「变更重评」**，不要只在群里说一声。

### 评审单与销售订单：1 对 1 还是 1 对多？

| 模式 | 适用 | 系统建议 |
|------|------|----------|
| **1 SO : 1 评审** | 常规整单生产 | 评审单号关联 SO；状态同步 |
| **1 SO 多行 : 1 评审** | 同工艺、同交期批次 | 评审覆盖 SO 行范围；MO 按行或按批下达 |
| **1 SO : N 评审** | 拆单交付、分批复产 | 每批复产单独评审；未批行不得下 MO |
| **变更单** | 客户加减量、换条款 | **新评审或变更重评**；旧 MO 完工/关闭规则写清 |

一期宁可 **先做 1:1**，也要在数据模型上 **预留评审单独立对象**（或 SO 上可追溯的评审历史），否则二期拆单会推倒重来。

### 会签分工（RACI 简表）

| 事项 | 销售 R | 计划 A | 采购 C | 财务 C | 质量/工艺 C | 系统 |
|------|:------:|:------:|:------:|:------:|:-----------:|------|
| 发起评审 | ● | | | | | SO→待评审 |
| 范围/BOM | C | ● | | | ● | 记录 BOM 版本 |
| 齐套日期 | I | ● | ● | I | | 缺料清单附件 |
| 贸易/税务 | ● | I | I | ● | | 订单类型 |
| 产能优先级 | I | ● | | | | 排程备注 |
| **终审放行** | I | ● | I | ● | I | 状态→通过，解锁 MO |

●=负责 · A=批准 · C=协商 · I=知情。终审不要五个人都能点「通过」——**一个批准角色**（通常是计划或工厂负责人）+ 其他人 **会签意见** 即可。

### 齐套：书面公式（评审附件必贴）

在蓝图里把「可用」写死，避免销售与仓库各算各的：

```text
计划可用量（某 SO 行）=
  仓库现存量（已质检合格）
− 全库已预留（含其他 SO）
± 是否计入「在途 PO」（进口在途是否算入，默认：只显示不自动预留）
± 是否计入「在产未入库」（仅当 MO 已下达且完工入库前，按规则显示）
```

**评审通过时** 必须在附件勾选：**在途是否参与承诺交期**（与 [出库前三问](./06-出海ERP-销售出库前系统必须回答的三个问题.md) 一致）。进口料「海上 3 周」若不算入，就不要在评审里写「下周齐套」。

### 评审通过后的标准链路（一期至少要能区分状态）

```text
合同/订单评审通过
    → 齐套检查（可用库存 + 在途 PO + 计划到货）
    → 缺料触发采购（本地采购合同 / 进口合同分轨）
    → 下达生产订单（MO）→ 领料 → 完工入库
    → 再按出库前三问做销售发货
```

**一期 ERP 不必一次做满 APS**，但要能做到：

1. **SO 与评审单关联**（或 SO 上有「评审状态」字段，未通过不可下 MO）。  
2. **采购分轨**：本地 PO 与进口 PO 在类型或路径上可区分（进口常伴货代服务 PO）。  
3. **入库与 SO 可追溯**：哪张 MO 喂哪张 SO，避免「库里有货但不知道给谁」。  

若一期只上进销存+财务、生产二期再上，也请在合同附件写：**评审与齐套在系统外怎么做、谁签字、多久迁入系统**——否则二期上线时要给历史订单补课评审状态，成本极高。

### 齐套：评审里最容易被轻写的半页纸

齐套不是仓库点一下「有/无」。进口主料在海上时，评审应写清：

- **齐套认定规则**：到厂未检能否算齐套？在途能否参与承诺（与 [出库第三问](./06-出海ERP-销售出库前系统必须回答的三个问题.md) 一致）？  
- **替代料**：是否允许、谁批、是否改 BOM 版本。  
- **拆单**：先交部分数量是否允许，余量评审是否重开。

计划常说「料下周到」；财务问「这周能不能认收入」——**齐套假设写在评审附件里**，月结争论会少一半。

### 和「贸易 / 自产」分支的衔接

评审单对 **转口贸易** 订单同样重要，但结论不同：可能评审结果是「不走 MO，走贸易 PO + 直发」，而不是排产。若评审不区分分支，贸易单也会被误下生产，又会出现 [决策树](./05-出海ERP-没库存时自产自销还是转口贸易.md) 里说的 **假工单**。

建议在评审单模板加勾选：**本单履约路径 = 有库存出库 / 自产自销 / 转口贸易**（与决策树一致）。IT 用订单类型或工作流把勾选映射到不同下游单据。

### 单据类型映射（方案级，不限定某一品牌）

| 业务动作 | 建议独立类型/序列 | 与评审的关系 |
|----------|-------------------|--------------|
| 销售订单 | 内销 SO / 外销 SO / 现货 SO | 无库存自产：**待评审→通过** 后才可确认 |
| 合同评审 | 评审单或 SO 状态字段 | 通过前 **阻断** MO、定向采购 |
| 制造订单 MO | 标准生产 / 返工（可选） | 必须关联 SO 行 + 评审号 |
| 采购订单 | 本地采购 PO / 进口 PO / 货代服务 PO | 由齐套缺料触发；进口与本地分轨 |
| 发货单 | 内销发运 / 出口发运 / 直发第三国 | 走出库前三问检查 |

开源 **Odoo** 常见落地：销售订单类型（`sale.order` 上 type 或团队规则）、制造单在「确认」前用自动化/审批检查 **自定义状态**；年费套件用 **订单类型 + 工作流** 达到同样 **硬阻断**。验收标准只有一条：**未通过评审的 SO，测试账号无法创建 MO**。

### 评审单最小字段清单（可贴合同附件）

1. 关联 SO 号、行号、产品、数量  
2. 履约路径（现货 / 自产 / 贸易）  
3. BOM/工艺版本、是否临时料  
4. 齐套日期、缺料清单、在途是否计入承诺  
5. 内/外销、贸易条款、法人、仓库  
6. 会签意见 + **批准人 + 日期**  
7. 变更记录（原评审号、变更原因）

### 一期验收怎么测（UAT 抽 3 单）

1. **有库存**：评审可简化，但仍有「允许发货」状态。  
2. **无库存自产**：无评审 → 系统 **禁止** MO；补评审 → 允许 MO。  
3. **无库存贸易**：评审指向贸易 PO，**不出现** MO。

任一条在测试库做不到，就不要在验收报告里写「生产模块已上线」。
