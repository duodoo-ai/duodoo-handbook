**标题：【出海 ERP】销售签的是「合同金额」，财务付的是另一本账——价外费用谁扛？**

> 延伸阅读「出海 ERP」第 10 篇 · 2026-10-27 发布  
> 专题「工贸 ERP · 分期与验收」见 [专栏索引](./README.md)  
> 上篇：[续读](./13-出海ERP-VAT内外销税额怎么体现.md)  
> 下篇：[续读](./15-出海ERP-集团调度与多公司边界.md)

做过海外制造项目的财务都懂：**运、保、佣跨月、多单叠在一起**，标准 ERP 里 **行内一次性摊进单价** 经常不够。得事先约定：**报关单怎么分摊、移动加权怎么跟、大批量是否允许导入分摊行**——否则月结全是手工补洞。销售嘴上说「这单 DDP 全包」，货代账单三张一起到，还是老剧本。

另一场更常见的拧巴：SO 只有 **一行合同金额**，没人把 **价外池** 钉在评审上。老板拍桌子，多半不是脾气差，是 **货款** 和 **运关保佣** 从来两套账。

下面用 **脱敏后的 15 分钟对齐**（人物与金额虚构），可转发销售+财务+IT 同场听。

---

**老板**：我就问一句，这单还能不能赚钱？

**销售**：能啊，合同金额在这里，客户认了的。

**财务**：认的是货款。佣金谁出？海运费谁出？报关谁出？你 SO 上没写，我月底只能进费用，毛利你自己算。

**IT**：贸易条款字段有，但评审附件里 **费用池表** 是空的，系统没法自动生成服务 PO——你们得先填纸再让我录。

**老板**：……所以？

**我（实施顾问口径）**：把 **六项价外** 在 **合同评审** 上打勾：佣金、海空运费、本地陆运、保险、报关费、关税/进口 VAT（销售 VAT 另见系列 **A9**）。每一项写 **卖方扛 / 买方扛 / 集团代付**。合同金额只对应 **货款行**；谁扛的，挂 **物料 PO 还是服务 PO**（**A8** 那套）。

---

### 六项价外，老板用耳朵记

1. **佣金**——渠道点数，别口头 3%，评审没字据，提成和毛利永远对不上。  
2. **海运费 / 空运费**——报价说「含运」还是「到港另议」，差一句就差一整张服务 PO。  
3. **本地陆运**——港口到仓、仓到客户，DDP 常全在卖方头上。  
4. **保险**——谁投保、受益人是谁，理赔扯皮时 SO 帮不了你。  
5. **报关费**——服务费，别和关税混在一个报销摘要里。  
6. **关税 + 进口环节税**——进库存还是进费用，和 **A9** 两条线，别塞进销售行税率。

**DDP 到客户仓**：卖方包里东西多，评审里最好有 **费用上限或比例**；**FOB 装运港**：进口段往往在买方或集团，工厂 SO 上的合同金额可能只是 **到厂货款**，别用同一个毛利公式硬套。

---

### IT 只落 8 个钩子（一期够）

| 钩子 | 放哪 |
|------|------|
| Incoterm（贸易条款） | 评审 + SO |
| 合同金额（货款） | SO 行合计 |
| 价外池勾选（六项承担方） | 评审附件 / 结构化备注 |
| 佣金规则 | 评审或 SO 备注规范 |
| 服务 PO 分轨 | 运费/报关/关税分项 |
| 评审号 → SO | 可追溯 |
| 无 PO 不付款货代 | 财务规则 |
| 代付对账清单 | 集团调度场景 |

二期再做「点选 Incoterm 自动带出模板」——一期 **能填、能挂附件、能指回 PO 号** 就过关。

**和到岸成本（Landed Cost）的关系**：价外池定 **谁承担**；到岸成本定 **怎么进库存单位成本**。实务上 **主流程走标准 Odoo**，**月结分摊**（报关单、多单运费）要么约定 **开发导入行**，要么 **财务人工路径**——别指望上线当周才第一次谈分摊。

---

### 自测 5 条（不用 UAT 表也行）

- 打开任一在产 SO：能说出 **六项里哪几项卖方扛** 吗？  
- 财务能否 **禁止** 无服务 PO 的货代付款？  
- 佣金是否在系统里有 **字据**（行/备注/附件）？  
- DDP 单是否至少一张 **服务 PO** 和物料 PO 并列？  
- 老板看毛利时，能否 **合同金额 − 已发生价外** 讲清楚？

五条里挂两条，别急着骂 ERP，先补 **评审费用池**。
