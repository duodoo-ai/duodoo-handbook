**标题：【出海 ERP】本地没库存时：自产自销还是转口贸易？一张决策树给财务和 IT**

> 延伸阅读「出海 ERP」第 1 篇 · 2026-10-20 发布  
> 专题「工贸 ERP · 分期与验收」见 [专栏索引](./README.md) · 下篇：[销售出库前三问](./06-出海ERP-销售出库前系统必须回答的三个问题.md)

销售在群里回客户「可以，下周发」；仓库说 **当地仓没货**；计划说产能满；采购说 **进口主料还在海上**——财务月底问：这笔算制造毛利还是贸易差价？若你们的 **海外制造主体** 同时做 **内销外销、本地采与进口采、自产与成品贸易**，却没有一张 **书面决策树**，ERP 再贵也只是把混乱电子化。

我按近年参与的一类 **出海制造基地**（多法人、集团调度、终点国可直发）梳理过业务骨架：**销售两种、采购两种、经营两种（自产、贸易）**。下面这张树，适合写进蓝图附件或合同「流程假设」——开源 Odoo 与年费套件都适用，变的是模块配置，不变的是 **分支不能合并记账**。

### 决策树（先业务，后系统）

```text
销售订单已确认
    │
    ▼
查「本国/本仓」可用库存（含已分配、在检，口径写死）
    │
    ├─ 有可用量 ──► 销售出库（自产库存或此前已入库的贸易库存）
    │
    └─ 无可用量
            │
            ├─ 本单标的能在本工厂生产且齐套可达 ──► 自产自销
            │       输入：合同/订单评审 → 排产 → 采购补料 → 生产 → 入库 → 销售出库
            │
            └─ 不能生产（产能、工艺、认证、物料）或标的为外购成品/设备/服务 ──► 转口贸易
                    输入：贸易采购 → 入库或直接直发 → 销售出库（成本按采购/费用归集，别走生产订单）
```

**三个名词别混用**

- **自产自销**：成本主干是 **BOM + 工单 + 入库**；收入仍是销售订单。没有真实生产，别硬开 MO 凑数。  
- **转口贸易**：价值来自 **采购价差 + 贸易条款下的费用**；系统里应是 **贸易 PO + 贸易库存或直发**，不要挂假工单。  
- **销售出库**：只是 **履约动作**；上面两条路径都可以出库，但 **前置单据链完全不同**。

### 财务和 IT 必须在立项时对齐的 5 件事

**1. 库存口径**  
「可用」是否扣减已锁单、在途未检、客供料？销售看到的 ATP 若比仓库多，决策树从根上就歪了。

**2. 评审单触发点**  
无库存且走自产时，建议 **强制合同评审/订单评审** 再排产——评审里写清：齐套日期、进口料到达假设、是否允许拆单交付。一期 ERP 至少要能 **挂评审状态**，别允许未评审直接下生产。

**3. 采购分轨**  
本地采购合同 vs 进口合同（产地、贸易术语、谁付关税/VAT/货代）要在主数据或订单类型里 **一眼可辨**。进口段常见：**物料 PO + 货代服务 PO**，费用进存货或费用池的规则一期就要定，别等关账时 Excel 分摊。

**4. 贸易条款进价外费用**  
合同金额之外，运费（本陆、海、目的陆）、保险、报关、佣金是否进入 **成本或销售费用**？DDP 类条款卖方责任重，系统若只记发票货值，毛利会虚高——这不是财务「事后调」，是 **订单类型模板** 该带的字段。

**5. 多法人谁录哪张单**  
集团接单、海外工厂生产、终点国直发客户时，经常出现 **三张销售、两张采购、两次货代**。决策树是 **单工厂视角**；集团调度要在接口或手工规则里写清 **法人边界**，否则「自产」记在 A 公司、出库在 B 公司，合并报表永远对不上。

### 系统里建议的「单据类型」映射（示例）

| 业务分支 | 典型输入单据 | 一期至少要能区分 |
|----------|--------------|------------------|
| 有库存履约 | 销售订单 → 发货单 | 库存组织、批次/产地（按 **合同约定产地**，勿与实物批次脱节） |
| 自产自销 | 评审 → 生产订单 → 完工入库 → 发货 | 工单与 SO 关联、超领与补料留痕 |
| 转口贸易 | 贸易 PO → 收货/直发 → 发货 | 无 MO 或 MO 数量为 0；采购成本归集方式固定 |

我见过最伤实施信任的一种：**销售单一种、出库一种、财务一种**。乙方说「都能做」，上线后每个无库存订单都在群里问「这单走产还是走贸」——那就是没树，只有模块。

### 脱敏片段：产能满了还要履约

某出海集团接到 **终点国客户** 订单，约定 **产地为海外制造基地**；国内产能已满，由 **当地法人工厂** 生产并可能 **直发客户仓**。此时集团对工厂是 **采购订单**，工厂对集团是 **销售订单**；工厂侧仍要走上面的树：本地无库存 → 评审 → 自产或外购料 → 再出库。  
若合同是 **DDP 客户仓**，卖方还要把进口清关、关税、VAT、段运费纳入 **成本与现金流假设**——树的分支定了，费用模板才跟得上。FOB 则风险转移点不同，**同一棵树，叶子上的贸易条款不同**，不能共用一套默认科目。

### 和「一期边界」的关系

自产/贸易 **不是二期才想** 的事。工厂主体一期若只上进销存+财务，也要在附件里写：**默认无库存订单走哪条分支、评审谁签字、贸易类库存是否独立仓**。否则二期加生产模块时，历史贸易单与生产单缠在一起，清洗成本比当初省下的蓝图时间贵一个数量级。

你若正在对标类似场景，建议先把：库存口径、评审触发、自产/贸易订单类型、进口费用归集 **整理成一页流程说明**，再和乙方对齐模块与人天——比直接问「Odoo 多少钱」少踩坑。
